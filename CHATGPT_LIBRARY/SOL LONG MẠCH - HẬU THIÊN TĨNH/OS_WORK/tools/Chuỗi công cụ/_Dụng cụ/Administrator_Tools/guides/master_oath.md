# Master OAth — đa điểm xác thực

Tuyến đã kết nối: Hostinger `search → execute → readback`; Gmail `get_profile` và `search_emails` chỉ khi challenge cần. Tài liệu `Master_OAth/README.md` là nguồn hành động. Web browser handoff khi thật sự cần phiên web, sử dụng trang chủ chính chủ. Server MCP hostinger `https://mcp.hostinger.com`; secret phải nằm trong secret store/process environment, không trong chat/repo/code/đối số dòng lệnh.

Không có browser callable thì thử connector hợp lệ thay vì báo đã đăng nhập. Chỉ công bố thành công phiên sau provider readback độc lập, không dùng biên nhận của workflow hoặc của đoạn mã local để tuyên bố OAuth hoàn tất.
